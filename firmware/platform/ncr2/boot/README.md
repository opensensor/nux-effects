# Stock boot-configuration evidence

`stock_boot_config.json` is a decoded, reviewable description of the boot
configuration in the verified NCR-2 dump. It records:

- the FCFB and source hashes;
- IVT pointers;
- BootData fields;
- DCD command boundaries; and
- all DCD register writes.

It is generated with:

```sh
python3 tools/open_image.py extract-boot \
  --dump dump1.bin \
  --json-output firmware/platform/ncr2/boot/stock_boot_config.json \
  --fragments build/open/stock_boot
```

The JSON contains hardware configuration facts rather than the full firmware
image. Raw FCFB/IVT/DCD fragments are emitted only under the ignored `build/`
tree.

The initial offline bootloader overlay reuses the exact first `0x2000` bytes
from the verified dump. Converting the FCFB and DCD into generated source is a
later gate: the source-generated bytes must match the known-good header before
they replace it.
