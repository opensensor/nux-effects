Install open engines

Web DFU installs a reviewed .slot application image containing open engines 5–8. It writes only the inactive A/B application slot and preserves the factory engines.

Disconnected

Enter Open Recover, connect it here, choose a built slot image, then install. Do not remove USB power during erase or write.
