# Preview audio

`clean-guitar-di.wav` is a six-second excerpt of `guitar_jam/train/001.wav`
from the [GuitarJam dataset](https://huggingface.co/datasets/Julian-br/GuitarJam).
The source is a clean Fender Stratocaster improvisation recorded directly
through a Focusrite Scarlett Solo, without an amplifier or effects.

The dataset is dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The excerpt
was trimmed from 0.45 seconds, resampled from 44.1 kHz to the pedal's 48 kHz
rate, kept mono at 16-bit PCM, and given a 100 ms fade at its six-second end.
